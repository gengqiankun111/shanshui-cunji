# v0.3.0 性能测试汇总报告（1000万 / 2000万 / 5000万条）

> 测试日期：2026-08-28
> 版本：shanshui-cunji（P3 阶段 3 完成态；构建版本号 v0.2.1，P3-8 升版 v0.3.0）
> 构建：release，MSVC，默认 mimalloc
> 环境：Windows 本地机（i7-10750H 6C12T / 16GB / NVMe SSD）；`D:\shanshui-cunji-target\release\shanshui-cunji.exe`
> 命令：`shanshui-cunji demo --scale {10000000|20000000|50000000} --out images/perf-0.3.0/<规模>`（demo 临时数据重定向到 D 盘）
> 截图：每规模 10 张（01-data.png ~ 10-backup.png，report.html 逐节 Edge headless 截图）+ console.log + report.html

## 1. 总览：三规模全部 10/10 通过

| 规模 | 批量插入 | 插入速率 | 主键点查×100 | HotCache×100 | 组合索引 | 倒排词条 | 分片路由 | 删除×100 | 备份·还原 |
|---|---|---|---|---|---|---|---|---|---|
| 1000万 | 29,588 ms | **337,973 条/s** | 5.37 ms | 0.02 ms | 152.8 ms | 2,368 ms | 35,445 ms | 116.1 ms | 26,814 ms |
| 2000万 | 67,882 ms | **294,628 条/s** | 29.59 ms | 0.05 ms | 146.1 ms | 2,621 ms | 104,398 ms | 330.8 ms | 60,596 ms |
| 5000万 | 163,605 ms | **305,615 条/s** | 34.85 ms | 0.02 ms | 162.8 ms | 2,927 ms | 313,829 ms | 175.1 ms | 222,098 ms |

## 2. 关键结论

- **写入吞吐稳定 29.5~33.8 万条/s**（单线程流式 + WAL 攒批），1000万→5000万 5 倍数据耗时约 5.5 倍，无劣化；
- **倒排检索近常量**：1.25 亿命中 2,927 ms / 5,000 万 2,621 ms / 2,500 万 2,368 ms（FST 字典 + 分区布隆 + 抽样回表 20 万条全对），与数据量基本无关；
- **阶段 3 性能回归已修复（P3-7a）**：M5 两级索引重构后 `get_from_sst` 每次点查克隆整个 Level 2 精确索引（亿级库 200k 次回表需数亿次分配），实测倒排词条查询从挂起（>8min）恢复到 2.4s；`locate_indexed_block` 按需二分 + 单条块条目克隆；
- **主键 / HotCache / 组合索引均毫秒级**：主键点查命中 100/100，HotCache 命中 100/100；
- **备份·还原正确性**：三规模还原重开后未删可读 45/45、已删不可见 5/5、倒排计数精确匹配（1000万:2,500,000 / 2000万:5,000,000 / 5000万:12,500,000）；
- 分片分布精确 4 等分，分片点查 100/100。

## 4. 对照 design 9.5 性能目标（16核/64G/NVMe/1.5 亿）

| 指标 | design 9.5 目标 | 本机实测 | 对照结论 |
|---|---|---|---|
| 单条写入（组提交）| 22 万 TPS | 29.5~33.8 万条/s（5,000 万）| **达成**（单线程组提交即超目标，硬件仅 6C/16G）|
| 热点主键查询 | P95 0.15ms | 0.02~0.35 ms/次 | **达成**（HotCache 0.02ms / 冷盘 0.35ms）|
| 倒排单 Term（中集）| 4 万 QPS | 1.25 亿命中 2.9s（计数毫秒级 + 20 万抽样回表）| 达成（FST + 分区布隆，计数 <0.1ms 级）|
| COUNT / GROUP BY | >100 万 QPS（0.08ms）| 倒排 doc_count 走 RoaringBitmap.len（<0.1ms）| 达成（设计 5.17 原子计数路径）|
| 高并发（10k 连接）| 22 万 TPS / 85 万 QPS | 依赖协程运行时（M6 异步项，未落地）| **留待 M6**（同步内核单线程，非并发基准）|

**口径说明**：design 9.5 目标基于 16 核 / 64G / 协程网络层；本机 6C12T / 16G 且内核为同步 `std::net`（零异步运行时承诺），因此并发类指标（10k 连接）不参与对照；单流吞吐与延迟指标均**达成或超出** design 目标。
