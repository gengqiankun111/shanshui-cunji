# v0.4.0 性能回归快检（1000万 单规模，M6 收尾）

> 测试日期：2026-08-28
> 版本：shanshui-cunji（M6 完成态；构建版本号 v0.3.0，打 v0.4.0 标签时升版）
> 构建：release，MSVC，默认 mimalloc；环境同 v0.3.0（i7-10750H 6C12T / 16G / NVMe）
> 命令：`shanshui-cunji demo --scale 10000000 --out images/perf-0.4.0/1000万`

## 结果：10/10 通过，M6 改动无性能回归

| 指标 | v0.3.0（1000万） | v0.4.0（1000万） | 变化 |
|---|---|---|---|
| 批量插入 | 29,588 ms（33.8 万条/s）| **25,899 ms（38.6 万条/s）** | +14%（同机能波动）|
| 主键点查×100 | 5.37 ms | 5.05 ms | 持平 |
| HotCache×100 | 0.02 ms | 0.03 ms | 持平 |
| 倒排词条（250 万命中 + 20 万回表）| 2,368 ms | 2,115 ms | 持平 |
| 分片路由 | 35,445 ms | 27,511 ms | +22%（波动）|
| 备份·还原 | 26,814 ms | 20,688 ms | +23%（波动）|

## 说明

- M6 改动（环形 WAL / Leveled-Compaction / MVCC 快照读 / 热点保护区 / 增量备份）均为**功能层**增强：
  - demo 走默认 append WAL（环形 WAL 由 `[storage] wal_mode="ring"` 显式开启）；
  - Leveled-Compaction 仅影响 `compact` 路径（demo 不触发）；Manifest 增加层号字段不影响读写热路径；
  - 热点保护区仅在访问计数达阈值时晋升，常规读路径无额外开销；
- 新增功能均有单元/集成测试覆盖（279 全绿）：环形 WAL 回环/回绕/崩溃恢复、Leveled L0→L1/L1→L2、
  MVCC 快照读历史版本/删除前快照、热点晋升/冷挤压存活、增量备份断点+还原。
