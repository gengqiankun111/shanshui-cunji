# 阶段 1.5 · PAX 混合列式数据块 验证记录

> 验证日期：2026-08-27 · M4 里程碑第 1/2 项：PAX 列式数据块 + 字段级 Zone Map

## 实现

- **SST v4**（`SST_VERSION=4`）：数据块引入块首 kind 字节（`0`=行式 / `1`=PAX 列式），同文件可混合；
  **向后兼容 v3**（旧行式文件无 kind，Reader 按 Footer 版本 + 块 kind 双重分发，新旧文件共存）。
- **PAX 块布局**：`RowCount → Keys → 列偏移量表（字段名+热/冷标记+偏移/长度）→ 热列组（块头）→ 冷列组（块尾）→ Seqs`；
  文档按 JSON 字段拆列（`serde_json preserve_order` 保序，重组与写入字节一致）。
- **热字段白名单**：配置 `[storage] hot_fields = [...]`，高频查询字段进热列组（块头），其余进冷列组（块尾）。
- **弱 schema 兜底**：列集 = 所有行字段并集（首行顺序 + 后续新字段追加），字段不丢失；非 JSON 值 / Tombstone → 整块回退行式。
- **字段级 Zone Map**：每块每列采集 `min/max/present/null` 计数，随 v4 索引编码（design 4.4.1 强化）。

## 验证

### 单元测试（128 全绿，+5 新增）
| 测试 | 覆盖 |
| --- | --- |
| pax_block_roundtrip_preserves_json_and_zones | PAX 拆/合保真（含 null/缺失字段）、字段级 Zone Map 计数 |
| pax_falls_back_to_row_for_non_json_or_tombstone | 非 JSON / Tombstone 回退行式 |

| pax_cf_flush_read_roundtrip | ColumnFamily 层 flush→读（JSON 保真 + raw 回退） |

### CLI 端到端（hot_fields 配置）
- `put` 3 条 JSON 文档（`[storage] hot_fields = ["status","city"]`）
- `backup` 触发刷盘 → 生成 **SST v4**（`sst-00000001.sst`，头部魔数 `NVSSTL01`、版本=4）
- 刷盘后 `get` 语义等值返回；`search device=android` 命中 2 条（倒排 + 从 PAX SST 回表）

```
文件: sst-00000001.sst 大小=588 魔数=NVSSTL01 版本=4
get 3003 → {"status":"active","type":"order","device":"android","city":"beijing","docid":3003}
```

## 结论

M4 第 1/2 项达成：PAX 列式块（列偏移量表 + 热/冷列组 + 配置白名单）+ 字段级 Zone Map + v3/v4 向后兼容。
存储格式变更集中在 sstable.rs（`SST_VERSION=4`），后续 TTL 时间分区 / Delta CF 复用 v4 读写路径。
