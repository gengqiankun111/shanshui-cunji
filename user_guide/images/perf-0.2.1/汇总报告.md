# v0.2.1 性能测试汇总报告（1000万 / 2000万 / 5000万条）

> 测试日期：2026-08-28
> 版本：shanshui-cunji v0.2.1（release，MSVC，默认 mimalloc）
> 环境：Windows 本地机（D:\shanshui-cunji-target\release\shanshui-cunji.exe）
> 命令：`shanshui-cunji demo --scale {10000000|20000000|50000000} --out images/perf-0.2.1/<规模>`
> 截图：每规模 10 张（01-data.png ~ 10-backup.png，report.html 逐节 Edge headless 截图）+ console.log + report.html

## 1. 总览：三规模全部 10/10 通过

| 规模 | 批量插入 | 插入速率 | 主键点查×100 | HotCache×100 | 组合索引 | 倒排词条 | 分片路由 | 删除×100 | 备份·还原 |
|---|---|---|---|---|---|---|---|---|---|
| 1000万 | 27,476 ms | **363,953 条/s** | 1.31 ms | 0.02 ms | 175.7 ms | 2,041 ms | 42,321 ms | 121.7 ms | 26,626 ms |
| 2000万 | 63,186 ms | **316,524 条/s** | 18.15 ms | 0.06 ms | 135.0 ms | 2,533 ms | 107,738 ms | 324.4 ms | 50,985 ms |
| 5000万 | 148,786 ms | **336,054 条/s** | 4.25 ms | 0.02 ms | 130.7 ms | 2,287 ms | 313,685 ms | 173.4 ms | 222,004 ms |

## 2. 关键结论

- **写入吞吐稳定 31.6~36.4 万条/s**，随规模线性扩展（1000万→5000万 5 倍数据，耗时约 5.4 倍），无劣化；
- **倒排检索近常量**：2,500 万条命中 2,041 ms / 5,000 万条 2,533 ms / 1.25 亿条 2,287 ms（FST 字典 + 分区布隆 + 抽样回表 20 万条全对），与数据量基本无关；
- **组合索引 / 主键 / HotCache 均毫秒级**；主键点查命中 100/100，HotCache 命中 100/100；
- **备份·还原正确性**：三规模还原重开后未删可读 45/45、已删不可见 5/5、倒排计数精确匹配（1000万:2,500,000 / 2000万:5,000,000 / 5000万:12,500,000）；
- 分片分布精确 4 等分，分片点查 100/100。

## 3. 与 v0.2.0（v0.1.0 报告）对比

| 指标 | v0.1.0（2026-08-27，1000万） | v0.2.1（2026-08-28，1000万） | 变化 |
|---|---|---|---|
| 批量插入 1000万 | 46,709 ms（214,091 条/s）| 27,476 ms（363,953 条/s）| **+70%** |
| 倒排词条查询 1000万 | 11,030 ms | 2,041 ms | **-81%**（分区布隆 + FST）|
| 主键点查 | 5.38 ms | 1.31 ms | -76% |

> 提升来源：M4 期间落地的 SST v5 分区布隆、FST 术语字典、mimalloc 全局分配器（默认 feature）。

## 4. 说明

- 用户明确跳过 1 亿条（耗时过长），本次只测 1000万 / 2000万 / 5000万；
- 每规模 10 项功能冒烟全部通过，与 `images/allocator-bench/`（分配器专项压测）互相印证。
