                              ┌─ 主键等值 → 点查（最快）
                              │
      ┌─ 单字段条件 ──────── 倒排（有）→ 组合（有）→ 全扫
      │  （price BETWEEN）
      │
WHERE ── 多字段组合 ──────── 匹配前2字段 → 组合（铁律优先）
      │  （a=1 AND b=2）      匹配前1字段 → 倒排（有）→ 组合
      │
      │                       ┌─ 等值 → 倒排 → 点查
      ├─ 单字段等值 ──────────┤
      │  （a=1）               └─ 关键字 → 倒排
      │
      └─ 无索引 ──────────── 全表扫描

这个逻辑是通用的，覆盖所有 WHERE 场景：

WHERE 后接	路由逻辑	是否覆盖
普通 SELECT	组合 → 回退 eval → 倒排 → 位图 AND	✓ 通用
SELECT ... ORDER BY	WHERE 求值路径同上，ORDER BY 在结果生成后排序	✓
SELECT ... GROUP BY	WHERE 求值同上，GROUP BY 在结果上聚合	✓
SELECT ... IN (...)	IN 走倒排多个等值 OR 合并，路由不影响	✓
SELECT ... WHERE ... GROUP BY ... ORDER BY	WHERE 阶段就是走上面的路由，后续聚合排序不影响	✓
WHERE 求值是所有查询的第一步，不管后面跟着 GROUP BY/ORDER BY/LIMIT，路由逻辑都适用。所以完整覆盖。
