- 目的：P134–P137（RR 快照读正确性 + 批量快照 API + 倒排 superset 接线 + 监控埋点）后跑
  Task-005 全量对比 MySQL，确认**正确性改动无性能回归**。
- 结论：**81/81 探针全部通过（OK 100%，0 失败，无卡死）**；SCC 相对 MySQL 的比值分布与
